# Rev. Iniobong Udoh Website

## Upload
Upload all files and the `assets` folder to the root of the GitHub repository, then import the repository into Vercel.

## Required before publishing
1. The portrait image is already included as `Rev Udoh.jpg`.
2. Contact email, phone/WhatsApp, and supplied social links are already connected.
3. Replace the placeholder biography when approved.

## Add another devotional
Open `devotionals.json`, add a comma after the current devotional object, and add another object using the same structure. Use dates in `YYYY-MM-DD` format. The site publishes according to the `Africa/Lagos` timezone.
